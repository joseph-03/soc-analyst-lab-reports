# SOC Analyst Lab Reports

Hands-on investigation and triage reports completed through the MyFirstHack 90-day cybersecurity foundation program (July to September 2026) and the TryHackMe SOC Level 1 learning path (in progress, expected December 2026).

All work was done in simulated labs and training environments. No real organisation data is included.

## Reports

**Alert triage and reporting**
- 01 SOC Alert Triage and Investigation: prioritising and classifying alerts as true or false positives
- 02 Alert Reporting and Escalation: writing alert reports using the Five Ws with escalation recommendations
- 03 Alert Enrichment and SOC Workbook: enriching alerts with identity inventories, asset inventories and network diagrams
- 04 Phishing Alert Triage: triaging a simulated alert queue (5 alerts: 3 true positives, 2 false positives)

**Endpoint, SIEM and log analysis**
- 05 EDR Endpoint Alert Triage: process trees, command lines and endpoint detections
- 06 SIEM Alert Investigation: correlation rules and alert investigation
- 07 Splunk Log Search: ingesting and searching VPN logs with SPL
- 08 Elastic VPN Investigation: Kibana and KQL log investigation

**Phishing, network and Linux investigation**
- 09 Wireshark Traffic Investigation: analysis of a 622-packet ARP capture
- 10 Phishing Email Analysis: sender, content and link analysis with a verdict
- 11 Linux Script Analysis: static analysis of a suspicious script
- 12 Linux Forensics Investigation: checklist-based review of a Linux system

## Tools and skills
Splunk (SPL), Elastic Stack / Kibana (KQL), Wireshark, EDR consoles, VirusTotal, Linux and Windows log review, MITRE ATT&CK and Cyber Kill Chain (foundational mapping).
